# **FakeLight**

_**Luces volumétricas falsas para simular focos o halos luminosos. Perfecto para efectos atmosféricos sin usar luces reales.**_

</header>

## Requisitos

* Unity **6000.3.10f1**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: Visual Effect Graph

## Contenido

* **VFX Graph:** `Projector`
* **Shader Graph:** `FakeLight_Cone`, `FakeLight_Sphere`, `FakeLight_Sphere_Displacement`, `FakeLight_Square`, `FakeLight_Water`, `Fake_Volumetric_LightShaft`, `SimpleFresnelShader`
* **Sub Graphs:** `WaterVertexDisplacement`
* **Scripts:** `LensFlareDataSRP`
* **Prefabs:** `FakeLight_Cone`, `FakeLight_Sphere`, `FakeLight_Sphere 1`, `FakeLight_Sphere Variant`, `VFX_Proyector`
* **Escenas:** `Assets/3-Scenes/Main.unity`

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.3.10f1**.
3. Abre la escena `Assets/3-Scenes/Main.unity` y pulsa **Play**.
